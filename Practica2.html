Punto 3. Predicción por Producto y Fecha: Mejor Modelo vs. Peor Modelo frente al Valor Real¶

La función predecir_por_producto_y_fecha(product_id, fecha_venta) busca el registro real del producto en la fecha indicada y compara frente a frente:

  1. Valor_Real (u): unidades realmente vendidas en esa fecha.
  2. Pred_Mejor_SVR (u) (Rank_01_SVR_poly_C5.0) y su Error_Mejor_%.
  3. Pred_Segundo_SVR (u) (Rank_03_SVR_rbf_C5.0).
  4. Pred_Peor_SVR (u) (Rank_24_SVR_sigmoid_C0.1) y su Error_Peor_%, demostrando cómo el modelo sin fine tuning adecuado colapsa hacia la mediana global y falla al capturar la escala del producto.

def predecir_por_producto_y_fecha(product_id, fecha_venta):
    """Predice la demanda de un producto en una fecha específica con el Mejor, Segundo Mejor y Peor Modelo SVR, y la compara con el Valor Real."""
    pid = int(product_id)
    if pid not in catalogo_dict:
        raise ValueError(f"El producto {pid} no existe. IDs válidos: {list(catalogo_dict.keys())}")

    filtro = (df_sales['product_id'] == pid) & (df_sales['fecha_venta'] == str(fecha_venta))
    if not filtro.any():
        fechas_disp = df_sales[df_sales['product_id'] == pid]['fecha_venta']
        raise ValueError(f"Fecha '{fecha_venta}' no encontrada. Rango válido: {fechas_disp.min()} a {fechas_disp.max()}")

    fila = df_sales[filtro].iloc[0]
    X_sample = pd.DataFrame([{
        'stock_en_momento': fila['stock_en_momento'],
        'discount': fila['discount'],
        'temperatura': fila['temperatura'],
        'dia_semana': int(fila['dia_semana']),
        'es_fin_de_semana': int(fila['es_fin_de_semana']),
        'holiday_flag': int(fila['holiday_flag']),
        'product_id': str(pid),
        'categoria': fila['categoria']
    }])

    valor_real = float(fila['cantidad_vendida'])
    pred_mejor = float(np.round(modelo_svm_mejor.predict(X_sample)[0], 1))
    pred_rbf   = float(np.round(modelo_svm_rbf.predict(X_sample)[0], 1))
    pred_peor  = float(np.round(modelo_svm_peor.predict(X_sample)[0], 1))

    err_abs_mejor = float(np.round(abs(valor_real - pred_mejor), 1))
    err_pct_mejor = float(np.round((err_abs_mejor / valor_real) * 100.0, 2)) if valor_real > 0 else 0.0

    err_abs_peor = float(np.round(abs(valor_real - pred_peor), 1))
    err_pct_peor = float(np.round((err_abs_peor / valor_real) * 100.0, 2)) if valor_real > 0 else 0.0

    return {
        "Producto_ID": pid,
        "Nombre": fila['nombre'],
        "Categoria": fila['categoria'],
        "Fecha": str(fecha_venta),
        "Dia": ["Lun", "Mar", "Mié", "Jue", "Vie", "Sáb", "Dom"][int(fila['dia_semana'])],
        "Valor_Real (u)": int(valor_real),
        "Pred_Mejor_Poly_C5 (u)": pred_mejor,
        "Error_Mejor_%": f"{err_pct_mejor:.2f}%",
        "Pred_RBF_C5 (u)": pred_rbf,
        "Pred_Peor_Sigmoid_C0.1 (u)": pred_peor,
        "Error_Peor_%": f"{err_pct_peor:.2f}%"
    }

def graficar_prediccion_dos_items(item_1=(4, "2024-04-08"), item_2=(70, "2024-05-18")):
    """
    Grafica y compara la predicción del Mejor Modelo y del Peor Modelo frente al Valor Real
    para 2 ítems específicos solicitados por el docente.
    """
    res_1 = predecir_por_producto_y_fecha(product_id=item_1[0], fecha_venta=item_1[1])
    res_2 = predecir_por_producto_y_fecha(product_id=item_2[0], fecha_venta=item_2[1])
    df_dos = pd.DataFrame([res_1, res_2])

    print("=== RESUMEN DE PREDICCIÓN PARA LOS 2 ÍTEMS ESPECÍFICOS (MEJOR VS. PEOR MODELO) ===")
    print(df_dos.to_string(index=False))

    fig = plt.figure(figsize=(15, 8.8))
    gs = fig.add_gridspec(2, 2, height_ratios=[1.12, 1.0], hspace=0.40, wspace=0.22)

    # Paneles superiores: Serie temporal de 60 días para el Ítem 1 y el Ítem 2
    for idx, (pid, f_str, res) in enumerate([(item_1[0], item_1[1], res_1), (item_2[0], item_2[1], res_2)]):
        ax = fig.add_subplot(gs[0, idx])
        df_p = df_sales[df_sales['product_id'] == int(pid)].copy().reset_index(drop=True)
        X_p = df_p[FEATURES].copy()
        X_p['product_id'] = X_p['product_id'].astype(str)
        df_p['Pred_Mejor'] = modelo_svm_mejor.predict(X_p)
        df_p['Pred_Peor']  = modelo_svm_peor.predict(X_p)

        ax.plot(df_p['fecha'], df_p['cantidad_vendida'], 'o-', color='#1565C0', lw=1.8, markersize=3.8, label='Valor Real Histórico')
        ax.plot(df_p['fecha'], df_p['Pred_Mejor'], 's--', color='#2E7D32', lw=1.8, markersize=3.8, label='Mejor SVR (Rank_01 poly C=5.0)')
        ax.plot(df_p['fecha'], df_p['Pred_Peor'], '^:', color='#E65100', lw=1.6, markersize=3.5, label='Peor SVR (Rank_24 sigmoid C=0.1)')

        fila_f = df_p[df_p['fecha_venta'] == str(f_str)].iloc[0]
        ax.scatter([fila_f['fecha']], [fila_f['cantidad_vendida']], color='#D32F2F', s=140, zorder=6,
                   label=f'Fecha consultada ({f_str})')
        ax.annotate(
            f"Fecha: {f_str}\nReal: {res['Valor_Real (u)']} u\nMejor SVR: {res['Pred_Mejor_Poly_C5 (u)']} u (Err: {res['Error_Mejor_%']})\nPeor SVR: {res['Pred_Peor_Sigmoid_C0.1 (u)']} u (Err: {res['Error_Peor_%']})",
            xy=(fila_f['fecha'], fila_f['cantidad_vendida']),
            xytext=(10, -18), textcoords='offset points', fontweight='bold', fontsize=8.4,
            bbox=dict(boxstyle='round,pad=0.35', fc='#FFF9C4', ec='#FBC02D', lw=1.2),
            arrowprops=dict(arrowstyle='->', color='#D32F2F', lw=1.4)
        )
        ax.set_title(f"Ítem {idx+1}: ID {pid} - {res['Nombre']} ({res['Categoria']})", fontsize=11, fontweight='bold')
        ax.set_xlabel('Fecha de Venta')
        ax.set_ylabel('Demanda (unidades)')
        ax.tick_params(axis='x', rotation=22)

    # Panel inferior: Comparación directa en barras de los 2 ítems específicos
    ax_bar = fig.add_subplot(gs[1, :])
    etiquetas_dos = [

Punto 6. Función de Predicción para un Nuevo Sample Hipotético (Mejor vs. Peor Modelo en 4 Casos + Sensibilidad)¶

La función predecir_nuevo_sample() permite ingresar cualquier nuevo escenario de simulación (stock disponible, descuento, temperatura, día de la semana y feriado) y devuelve simultáneamente la predicción del Mejor Modelo (Rank_01_SVR_poly_C5.0), del Segundo Mejor Kernel (Rank_03_SVR_rbf_C5.0) y del Peor Modelo (Rank_24_SVR_sigmoid_C0.1), evaluada en 4 casos de categorías distintas y en un análisis de sensibilidad al descuento.

rango_hist = df_sales.groupby('product_id')['cantidad_vendida'].agg(['min', 'max']).to_dict(orient='index')

def predecir_nuevo_sample(product_id, stock_en_momento, discount=1.0, temperatura=18.0,
                          dia_semana=2, holiday_flag=0):
    """Predice la demanda para un nuevo sample con el Mejor Modelo SVR, el Mejor RBF y el Peor Modelo SVR."""
    pid = int(product_id)
    if pid not in catalogo_dict:
        raise ValueError(f"Producto {pid} no existe en el catálogo: {list(catalogo_dict)}")

    info_prod = catalogo_dict[pid]
    es_finde = 1 if int(dia_semana) >= 5 else 0

    nuevo_df = pd.DataFrame([{
        'stock_en_momento': stock_en_momento, 'discount': discount, 'temperatura': temperatura,
        'dia_semana': dia_semana, 'es_fin_de_semana': es_finde, 'holiday_flag': holiday_flag,
        'product_id': str(pid), 'categoria': info_prod['categoria']
    }])

    pred_mejor = float(np.round(modelo_svm_mejor.predict(nuevo_df)[0], 1))
    pred_rbf   = float(np.round(modelo_svm_rbf.predict(nuevo_df)[0], 1))
    pred_peor  = float(np.round(modelo_svm_peor.predict(nuevo_df)[0], 1))

    r_min, r_max = rango_hist[pid]['min'], rango_hist[pid]['max']
    alerta = "ALERTA: Quiebre de Stock (Reabastecer)" if pred_mejor > stock_en_momento else "OK: Stock Suficiente"

    return {
        "Producto_ID": pid, "Nombre": info_prod['nombre'], "Categoria": info_prod['categoria'],
        "Stock_Disp": stock_en_momento, "Descuento": discount,
        "Fin_de_Semana": "Sí" if es_finde else "No", "Feriado": "Sí" if holiday_flag else "No",
        "Pred_Mejor_Poly (u)": pred_mejor, "Pred_RBF (u)": pred_rbf, "Pred_Peor_Sigmoid (u)": pred_peor,
        "Rango_Hist (u)": f"{r_min}-{r_max}",
        "Dictamen_Inventario": alerta
    }

8.2 Conclusiones Detalladas de Cada Punto¶

  1. Conclusión del Punto 1 y 2 (Limpieza de Datos, Ingeniería de Variables y Preprocesamiento):

    • La auditoría de calidad sobre los 600 registros (10 productos durante 60 días continuos) confirmó 0 valores nulos y 0 duplicados. La descomposición de fecha_venta en dia_semana y es_fin_de_semana, combinada con StandardScaler para las 6 variables numéricas, OneHotEncoder para product_id y categoria, y la transformación logarítmica del objetivo (TransformedTargetRegressor con $\log(1+y)$), fue indispensable para estabilizar la varianza entre productos de baja rotación (media de 31 u/día en Laptops) y alta rotación (media de 6272 u/día en Cables HDMI).

  2. Conclusión del Punto 3 de Experimentación (Fine Tuning de las 24 Combinaciones: 4 Kernels × 6 Valores de $C$):

    • La exploración exhaustiva de las 24 combinaciones demostró que la elección conjunta del kernel y del parámetro de regularización $C$ reduce el RMSE desde 2151.42 unidades en el peor modelo (Rank_24_SVR_sigmoid_C0.1, $R^2 = -0.1147$) hasta 574.37 unidades en el mejor modelo (Rank_01_SVR_poly_C5.0, $R^2 = 0.9206$), lo que equivale a una reducción del 73.3 % en el error cuadrático medio.
    • El valor $C = 5.0$ resultó ser el punto óptimo para los tres kernels válidos de Mercer (poly, rbf y linear): valores pequeños ($C \in \{0.1, 0.5\}$) provocan subajuste severo (el modelo ignora las diferencias entre productos), mientras que valores muy altos ($C = 100.0$ en el kernel polinómico, RMSE = 666.84 u) empiezan a sobreajustar el ruido del entrenamiento.

  3. Conclusión del Registro y Comparativa en MLflow (Runs, Models y Parallel Coordinates):

    • El registro estructurado en MLflow permitió comparar las 24 corridas bajo 6 métricas simultáneas de validación cruzada y prueba (RMSE_CV, STD_CV, RMSE_Train_CV, RMSE_Test, MAE_Test y R2_Test), aislando en la pestaña Models los 4 mejores modelos globales (Rank_01_SVR_poly_C5.0, Rank_02_SVR_poly_C10.0, Rank_03_SVR_rbf_C5.0 y Rank_04_SVR_rbf_C100.0), todos con $R^2 > 0.908$.

  4. Conclusión del Punto 3 y 4 de Predicción (Predicción por Producto y Fecha y Gráfica de 2 Ítems Específicos: Mejor vs. Peor Modelo):

    • Al evaluar los 2 ítems específicos solicitados frente al Valor Real del dataset:
      • En el Ítem 1 (product_id=4, Cable HDMI 4K, fecha 2024-04-08, Valor Real = 3000 u): el Mejor Modelo (Rank_01_SVR_poly_C5.0) predijo 3007.0 u (error de solo 0.23 %), mientras que el Peor Modelo (Rank_24_SVR_sigmoid_C0.1) predijo apenas 409.8 u (error del 86.34 %).
      • En el Ítem 2 (product_id=70, Monitor LG 24", fecha 2024-05-18, Valor Real = 4037 u): el Mejor Modelo predijo 4042.8 u (error de solo 0.14 %), mientras que el Peor Modelo predijo 429.0 u (error del 89.37 %).
    • Esto demuestra gráficamente que el peor modelo (sigmoid con $C=0.1$) entrega una predicción casi plana cercana a 350–400 unidades sin importar el producto ni la fecha, mientras que el modelo afinado (poly con $C=5.0$) reproduce con fidelidad los picos reales de demanda.

  5. Conclusión del Punto 5 y 6 (Auditoría por Producto, Nuevos Samples Hipotéticos y Sensibilidad al Descuento):

    • La función predecir_nuevo_sample(), evaluada en 4 productos de distintas categorías (Accesorios, Audio, Computación y Telefonía), mantiene todas sus estimaciones dentro de los rangos históricos reales de cada producto y detecta oportunamente los escenarios de quiebre de stock.
    • En la prueba de sensibilidad sobre el producto ID 38 (Parlante Bluetooth BLUE Bass), aplicar un 20 % de descuento (discount=0.80) incrementa la demanda estimada por el Mejor Modelo en +81.3 % (152.5 u $ ightarrow$ 276.5 u), mientras que el Peor Modelo apenas cambia un +5.9 % (341.6 u $ ightarrow$ 361.9 u), siendo incapaz de capturar la elasticidad precio-demanda.

  6. Conclusión del Punto 7 (Explicabilidad mediante Permutation Feature Importance):

    • En los modelos ganadores (Rank_01_SVR_poly_C5.0 y Rank_03_SVR_rbf_C5.0), las variables con mayor impacto en la reducción del RMSE son la identidad y categoría del producto (product_id: +1384.39 u; categoria: +1152.72 u), seguidas del indicador de día feriado (holiday_flag: +1070.91 u), el descuento (discount: +1051.87 u) y el efecto fin de semana (es_fin_de_semana: +124.99 u). En cambio, en el Peor Modelo (Rank_24_SVR_sigmoid_C0.1), la importancia de todas las variables es cercana a cero (máximo +20.9 u), confirmando que un SVR subajustado no extrae señal de las variables predictoras.

8.3 Recomendaciones Técnicas y de Negocio por Cada Punto¶

  1. Recomendación sobre Preprocesamiento y Escala del Objetivo (Puntos 1 y 2):
    • En problemas de demanda retail multi-producto con alta asimetría (ventas desde decenas hasta decenas de miles de unidades), se recomienda mantener siempre el escalado estandarizado de predictores (StandardScaler) junto con TransformedTargetRegressor(func=np.log1p, inverse_func=np.expm1) en SVR, ya que evita que los productos de alto volumen dominen la función de pérdida $\epsilon$-insensible.
  2. Recomendación sobre Selección de Kernel y Fine Tuning de Hiperparámetros (Punto 3 de Experimentación):
    • Se recomienda descartar el kernel Sigmoide con valores bajos de $C$ para regresión de demanda y priorizar los kernels Polinómico de grado 2 (poly, $C \in [5, 10]$) y RBF Gaussiano (rbf, $C \in [5, 100], \gamma pprox 0.02$), validando siempre mediante $K$-Fold Cross-Validation (RMSE_CV vs. RMSE_Train_CV) para vigilar la brecha de sobreajuste.
  3. Recomendación sobre Gestión del Ciclo de Vida en MLflow:
    • Se recomienda registrar únicamente los modelos que superen el umbral de calidad ($R^2 > 0.90$) en el Model Registry (Models) de MLflow para mantener limpio el catálogo de despliegue, conservando las 24 corridas completas en Runs como respaldo auditable de experimentación.
  4. Recomendación Operativa para Planeación de Inventario y Promociones (Puntos 3 a 7):
    • Utilizar Rank_01_SVR_poly_C5.0 integrado en la función predecir_por_producto_y_fecha() y predecir_nuevo_sample() para programar órdenes de reabastecimiento con al menos 48 horas de anticipación antes de fines de semana, feriados o campañas de descuento ($\ge 10\%$), dado que holiday_flag y discount son los dos impulsores exógenos más fuertes de quiebres de stock.
